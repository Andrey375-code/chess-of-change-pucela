## 1. ¿Qué es? / What is it?

Variante de ajedrez sobre el tablero estándar 8×8 con **46 posiciones iniciales** (30 con el caballo como guardián + 16 con el alfil). Mecánicas propias: **inmunidad del rey**, victoria por **«Disparo del Rey»**, **portales** y **transformación de la dama**.

A chess variant on the standard 8×8 board with **46 starting positions** (30 with the knight as guardian + 16 with the bishop). Own mechanics: **king immunity**, victory by **“King’s Shot”**, **portals** and **queen transformation**.

## 2. Cómo ejecutar el juego

1. **Opción A (en línea, un clic):** abra <https://andrey375-code.github.io/chess-of-change-pucela/> en cualquier navegador moderno (Chrome, Edge, Firefox, Safari), en ordenador, móvil o tableta.
2. **Opción B (sin conexión):** descargue el archivo `Chess_of_Change_Pucela.html` y ábralo con doble clic (ordenador) o con «Abrir con» → Chrome (Android). No requiere instalación.

Al abrirlo por primera vez aparece una pantalla para **elegir idioma** (English / Español / Русский); elija **Español**. A continuación se muestran las reglas y puede empezar a jugar.

## 2. How to run the game

1. **Option A (online, one click):** open <https://andrey375-code.github.io/chess-of-change-pucela/> in any modern browser (Chrome, Edge, Firefox, Safari) on a computer, phone or tablet.
2. **Option B (offline):** download the file `Chess_of_Change_Pucela.html` and open it by double-click (computer) or “Open with” → Chrome (Android). No installation required.

On first launch a **language screen** appears (English / Español / Русский); choose your language. The rules are then shown and you can start playing.
